# REC Gen 16 press materials

Drop current Gen 16 campaign artwork into this folder. It appears in the “Ấn phẩm” window opened from the top navigation; it does not add more page scrolling.

- Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`
- Use numbered filenames to control order, for example `01-Lich-tuyen-thanh-vien.jpg` and `02-The-Real-Contest.png`.
- The filename becomes the title shown under the artwork. Vietnamese names are supported.
- Keep portrait artwork at its original proportions; the gallery shows the full image without cropping.
- The `gen15` subfolder contains visual material recovered from last year's saved website. It is shown as a clearly labelled archive.

After adding files at this folder's top level, rebuild/redeploy the site so Vite includes them as Gen 16 material.
