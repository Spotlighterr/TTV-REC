# Earth textures

Downloaded from the official Three.js examples texture collection:

- earth-day.jpg: https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg
- earth-normal.jpg: https://threejs.org/examples/textures/planets/earth_normal_2048.jpg
- earth-water.jpg: https://threejs.org/examples/textures/planets/earth_specular_2048.jpg
- earth-clouds.png: https://threejs.org/examples/textures/planets/earth_clouds_1024.png

Source collection: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

Images are unmodified. Display lighting and a separate geographic overlay are
applied at runtime. The geographic overlay uses the Natural Earth dataset credited
in the project README.
